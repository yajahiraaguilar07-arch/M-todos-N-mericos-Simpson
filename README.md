Métodos Numéricos: Simpson 1/3 Compuesto

Descripción

Este proyecto implementa el método de Simpson 1/3 compuesto en Java y permite compararlo con el método del trapecio compuesto para aproximar integrales definidas.

Objetivos

- Implementar el método de Simpson 1/3 compuesto.
- Calcular aproximaciones numéricas de integrales definidas.
- Comparar los resultados de Simpson y del trapecio compuesto.
- Analizar el comportamiento del error numérico.

Archivos del proyecto

- "SimpsonCompuesto.java": implementación del método de Simpson 1/3 compuesto.
- "TrapezoCompuesto.java": función matemática y operaciones del método del trapecio compuesto.

Función utilizada

Se utiliza provisionalmente la función:

f(x) = e^(-x²)

Características

- Utiliza subintervalos para aproximar integrales.
- Simpson requiere un número par de subintervalos.
- Permite refinar la aproximación mediante una tolerancia de error.

Tecnologías

- Lenguaje Java.
- Plataforma GitHub para el almacenamiento y control de versiones.
